# ADASH

Yazılım, yapay zekâ ile kodlama ve teknoloji projeleri üretenlerin topluluğu.

## Geliştirme

```bash
npm install
npm run dev
```

Yerel ağda: `http://<bilgisayar-ip-adresi>:3000`

## Kullanım notu

Bu proje eğitim, inceleme ve uyarlama amacıyla kullanılabilir. ADASH markasını, kimliğini veya topluluğunu taklit etmek amacıyla kullanılamaz.
